## Outcome and files

Repair the first-turn provider call in `agents/llm.py`. Introduce a small runtime
contract/settings module and packaged YAML defaults. Use serializable dictionary
messages, paired call IDs/results and exactly one assistant message per response.
Return final text and expose typed status/usage. Serialize turns without holding
state locks during providers, retrieval, tools or subscriber callbacks. Snapshot
event subscribers during dispatch. Preserve existing methods and event names.

## Constraints and failure behavior

No paid/provider calls in tests. No UI redesign or Git/tool policy changes here.
Keep a complete history; remove the automatic message-count trimming path until
S11 provides model-aware context selection. Manual compaction must retain complete
user turns and archive older turns before removing them. Queued inputs stay queued
until the current tool protocol group finishes. Malformed tool input becomes a
tool result, not a worker crash. Transient retries and tool rounds are finite and
configurable; cancellation can stop waits and the next loop boundary. S06 extends
this to active subprocess/HTTP cancellation.

## Evidence gates

Fake clients cover first/multiple turns, text+multiple tools, malformed arguments,
tool exceptions, unknown tools, serialized history, subscriber reentrancy, no
automatic history loss, bounded loops, cancellation and transient/permanent
failure behavior. Event-bus snapshot dispatch tests cover subscription changes.
