## Required behavior

- Config reads validate object roots and known fields without writing during
  migration. Unknown/custom data survives. A malformed original remains intact;
  a later explicit save preserves a recoverable copy first. Untagged customized
  prompts must not be overwritten as stale defaults.
- Save with unique private temporary files, flush/fsync, atomic replacement and
  a process lock. Current/default schema versions agree. Report save failure
  honestly; never publish a false success notification.
- Keep `MYTHIC_HOME` isolation and support an explicit ConfigManager root for
  tests/embedding. Move configuration defaults into packaged data.
- Versioned sessions live under workspace identity, with validated session IDs,
  dictionary messages and terminal outcomes. List, resume and export through CLI.
  Save at meaningful turn/tool boundaries and after failures/cancellation.
- A per-session turn lease prevents concurrent processes from overwriting a
  resumed conversation. Prepared/incomplete tool calls become explicit interrupted
  results during recovery; do not re-execute potentially completed side effects.
- Preserve the stored transcript independently of selected model context. Manual
  clear/compact updates context while historical transcript remains retrievable.
- Redact configured/environment credentials in diagnostic/export data; do not
  print or inspect live secret values. Keep private configuration/session files
  under application state. No credentials created or copied to new destinations.

## Invariants and limits

isolation is implemented here; legacy core/vector memory migration and model-aware
context are S11. Sharing one runtime across human/machine sessions must preserve
complete tool-call/result groups and support another turn after a failure.
All mandatory provider tests use localhost fixtures, with no hosted costs.
