## Intentional exclusions

- `mythic_agent/__init__.py` and every subpackage `__init__.py`:
  package-namespace modules, not module APIs; they re-export via plain
  imports. Enforced in `tests/test_public_api.py::INTENTIONALLY_PRIVATE`.
- Modules that cannot import in a minimal environment (`textual`,
  `mcp`, `piper-tts` missing) are still AST-scanned for `__all__`
  presence; the attribute-existence rot check runs only where importable.
